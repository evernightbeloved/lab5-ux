# Лабораторная работа №5 — Адаптивный дизайн и UX-аудит

Проект основан на сайте из лабораторной №4.

Реализовано:
- три брейкпоинта: desktop >=1024, tablet 768–1023, mobile <768;
- CSS Grid/Flex;
- переключение светлой/тёмной темы;
- счётчик кликов;
- реакция на высокую активность после 5 кликов;
- сохранение темы и счётчика через localStorage;
- адаптивная навигация и карточки;
- кликабельные зоны не менее ~44px для кнопок.

Для отчёта нужны личные скриншоты:
1. Desktop.
2. Tablet через DevTools Device Toolbar.
3. Mobile через DevTools Device Toolbar.
4. Светлая тема.
5. Счётчик >= 5 кликов с сообщением.
6. Network с временем загрузки.
