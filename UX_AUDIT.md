# UX-аудит

Проверяем:
- удобство навигации;
- читаемость текста;
- отсутствие горизонтальной прокрутки;
- корректное масштабирование изображения;
- размер кликабельных зон;
- перестроение карточек на 3 брейкпоинтах;
- тему день/ночь;
- счётчик событий и сообщение при высокой активности.

## Скорость = деньги
В DevTools -> Network зафиксировать время полной загрузки и размер ресурсов.
В отчёте объяснить: увеличение задержки ухудшает пользовательский опыт, повышает вероятность ухода пользователя и может снижать конверсию.

## Битва конкурентов
Сравнить демо-сайт ReadyScript с Ozon/Wildberries:
- скорость;
- удобство поиска;
- визуальная структура.
